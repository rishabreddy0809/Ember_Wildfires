Clustering vs. Machine Learning: Identifying Real Wildfires from Harmonized MODIS and VIIRS Satellite Data

Satellites flag thousands of hot spots on Earth every day. Some are wildfires. Others are hot ground, factories, or sunlight reflecting off a surface. This project tests which approach is better at telling them apart: a clustering algorithm or a machine learning model.

The experiment is still running, so there are no results yet.

Every point on this globe is a satellite fire detection

These are all 136,676 detections that NASA’s FIRMS system recorded from MODIS and NOAA-20 VIIRS on Nov 7–8, 2026. Most of them are in Africa, where seasonal burning is common.

The instruments don’t see flames. They look for thermal anomalies: spots much hotter than the ground around them. Larger points gave off more fire radiative power.

Two instruments, MODIS and VIIRS, see the ground differently

MODIS flies on the Terra and Aqua satellites and sees pixels about 1 km wide. VIIRS flies on Suomi NPP, NOAA-20, and NOAA-21 and sees pixels about 375 m wide (Giglio et al., 2016; Schroeder et al., 2014).

Each satellite scans a wide strip of the planet, called a swath, as it orbits. The orbits drawn here are illustrations, not real positions.

One fire shows up as many detections

This is California on the same day, with 133 detections. Put both datasets on one map and a single fire becomes a cluster of overlapping MODIS and VIIRS points.

MODIS pixels also stretch toward the edge of each scan. There, one pixel can cover about 9.67 times the area of a pixel directly below the satellite (Giglio et al., 2016), and can overlap anywhere from about 1 to 115 VIIRS pixels (Zheng et al., 2026).

Not every detection is a real fire

False alarms come from hot bare ground, industrial facilities, and sun glint (sunlight reflecting off a surface). This project compares two ways of sorting real fires from false alarms.

Read how the experiment works

1Why combine MODIS and VIIRS?

Each sensor misses fires that the other one catches. Small, low-intensity fires (under 30 megawatts) are especially easy to miss. In a study that compared satellite detections with Landsat fire observations in North America, MODIS detected 26.76% of these fires and VIIRS detected 44.25%. A product combining both detected 54.44% (Zheng et al., 2026).

The sensors also fail in different ways. VIIRS sees finer detail, but it can miss fires hidden under heavy smoke or clouds that MODIS still detects.

When they do detect something, both sensors are usually right. In Serra da Canastra National Park in Brazil, researchers checked detections against 220 mapped fire scars. They confirmed 99.4% of VIIRS detections and 95% of MODIS detections, but both sensors often missed fires smaller than 1 km² (Pinto et al., 2024).

Combining the two sensors finds more fires, but it also stacks up duplicate detections and false alarms. Sorting real fires from that noise is the problem this project studies.

2Research question and hypothesis

Research question

Does a Random Forest machine learning model or a spatial-temporal clustering algorithm more accurately identify real wildfires from combined MODIS and VIIRS satellite data, as measured against known wildfire perimeters?

Hypothesis

If a spatial-temporal clustering algorithm and a Random Forest model are both used to identify real wildfires from combined MODIS and VIIRS data, then the Random Forest model will achieve higher precision and recall when compared with known wildfire perimeters, because additional characteristics of each detection can be used to recognize false alarms that clustering would group as fires.

How accuracy is measured

Precision
Of everything a method called a fire, the fraction that really was one. real fires flagged ÷ everything flagged
Recall
Of all the real fires, the fraction the method caught. real fires flagged ÷ all real fires

3Why one fire becomes many detections

A satellite sensor sweeps from side to side as the satellite moves forward. Directly below it, the pixels are small. Toward the edge of the swath, each MODIS pixel covers more ground, and neighboring rows start to overlap. A single fire can therefore be detected several times by the same sensor, then again by the other sensor.

4Methods being compared

4.1Spatial-temporal clustering (DBSCAN)

Real fires usually produce many detections close together. DBSCAN groups detections that are within 1,000 m and 24 hours of each other. Each group counts as a real fire, and a detection with no neighbors counts as a false alarm (Ester et al., 1996). Similar clustering has been used to map fire perimeters and burned areas (Briones-Herrera et al., 2020; Lizundia-Loiola et al., 2020).

4.2Random Forest (machine learning)

A Random Forest is a collection of decision trees. Each tree asks a series of yes/no questions about a detection, and the trees vote on the answer (Breiman, 2001). The model learns from examples that are already labeled “fire” or “false alarm.” It is built with scikit-learn (scikit-learn developers, n.d.). Machine learning is already used for satellite wildfire monitoring (Kang et al., 2023).

For each detection, the model uses: brightness temperature, fire radiative power, confidence, day or night, which sensor detected it, and the number of nearby detections.

4.3Control

Every detection is treated as a real fire, with no filtering. This is the baseline both methods are measured against.

5Procedure

  1. Download MODIS and VIIRS fire detections for California, June to November of 2020 and 2021, from NASA FIRMS.
  2. Download CAL FIRE fire perimeter data to use as ground truth.
  3. Label each detection: inside a real fire perimeter = real fire; far from any perimeter = false alarm.
  4. Train the Random Forest on 2020, then test both methods on 2021, so neither one has seen the test data.
  5. Measure precision and recall for clustering, Random Forest, and the control.
  6. Repeat for each month of the 2021 season (6 trials) and compare the methods with a paired t-test.

6The tool: Ember

Before testing any method, I needed to see the raw data. Ember is a macOS app I built with SwiftUI and MapKit. It downloads live and archived detections from the NASA FIRMS API and shows every individual MODIS and VIIRS detection on a satellite map. Overlapping detections and false alarms are included. You can turn each sensor on and off, click any detection to see all of its data, and export the combined data as a CSV file for analysis in Python.

8Limitations

  • Fire perimeter records don’t include every small fire, so some real fires may be labeled as false alarms.
  • Perimeters show the final burned area, not how the fire spread from day to day.
  • The study only uses California, so the results may not apply to other regions.
